# Securing Federated Learning Environments Against Coordinated Data Poisoning Attacks

## Project Overview
This repository contains the Pre-Graduation Project 1 at the Faculty of Artificial Intelligence Engineering, Syrian Private University (SPU). The project focuses on securing distributed federated learning against coordinated data poisoning attacks through automated network-level isolation.
